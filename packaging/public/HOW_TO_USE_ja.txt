==============================================================
 PyEmuera 3.0.0 Beta 2（ぱみゅーら） 使い方ガイド
 ― コマンド操作に慣れていない方向け ―

はじめての方向けに順番に説明します。
Windows 10 / Windows 11 を前提にしています（Linux は 11章）。
Windows 11 の十分な実機検証は完了していません。

--------------------------------------------------------------
1. PyEmuera とは
--------------------------------------------------------------

Emuera 用のバリアント（ERB・CSVで作られたゲーム）を、
文字だけの画面で動かすプログラムです。
「Python（パイソン）」という、プログラムを動かすためのソフトの上で動きます。

できること
  ・バリアントフォルダーをそのまま読み込んで遊ぶ（バリアントのファイルは書き換えません）
  ・Emuera で作った既存のセーブデータを読み込む
  ・バリアントを始める前に、読み込めない行がないかを確認する

できないこと
  ・本家GUIの画像、音声、マウス操作、フォント描画の再現
    （端末そのもののフォント設定は利用できます）
  ・Emuera の拡張版（EE / EM）専用の機能
  ・すべてのバリアントが最後まで同じように動くことの保証
    （詳しくは KNOWN_ISSUES_ja.txt を見てください）

Emuera 本体（Emuera.exe）は必要ありません。

この文書に出てくる言葉
  ・Python ………… PyEmuera を動かすためのソフト。別途インストールします（2章）。
  ・PyEmuera.pyz … PyEmuera 本体のファイル。Python で実行します。
  ・.bat ファイル … ダブルクリックやドラッグ＆ドロップで PyEmuera を起動するためのファイル。
  ・コマンド プロンプト … 文字を入力してパソコンを操作する黒い画面。
                          この文書では、Python の確認（2章）と 11章でだけ使います。


--------------------------------------------------------------
2. Python を用意する
--------------------------------------------------------------

PyEmuera を動かすには Python 3.10 以上が必要です。

  Windows 10とLinuxで動作確認しています。
  Python 3.10以上を使用してください。Python 3.15以降は未検証です。
  動作確認は、実際に使用した環境・バリアント・実行経路の範囲に限られます。

■ 2-1. コマンド プロンプトを開く

  (1) 画面左下のスタートボタン（または検索欄）をクリックします。
  (2) キーボードで「cmd」と入力します。
  (3) 一覧に「コマンド プロンプト」が出たら、クリックして開きます。
      黒い（または白い）文字入力の画面が開きます。

■ 2-2. すでに Python が入っているか確認する

  コマンド プロンプトに次の文字を入力して、Enter キーを押します。

        python --version

  結果を見ます。
    ・「Python 3.10」以上（3.11、3.12、3.13、3.14 など）と表示された
        → 準備完了です。3章へ進んでください。
    ・Microsoft Store が開いた、または「Python was not found」と表示された
        → 2-3 へ進んでください。
    ・「Python 3.9」以下が表示された
        → 古いので、2-3 の手順で新しい Python を入れてください。

■ 2-3. Python を入れる

  Python 公式の「Python install manager（Python インストール マネージャー）」を使います。
  次のどちらかの方法で入れてください。

    ・方法A：Microsoft Store アプリで「Python Install Manager」を検索し、
            「インストール」を押す。
    ・方法B：https://www.python.org/downloads/ から Windows 用の
            インストール マネージャーをダウンロードし、ダブルクリックして
            「Install」を押す。

  インストールが終わったら、コマンド プロンプトを一度閉じて開き直し、
  もう一度「python --version」と入力して Enter を押してください。

    ・Python 本体がまだ入っていない場合は、このとき最新版の Python が
      自動でダウンロード・インストールされます（インターネット接続が必要です）。
      画面の案内に従ってください。
    ・はじめて Python 本体を入れるとき、フォルダーを PATH に追加するか
      聞かれることがあります。これは任意の設定で、どちらを選んでも
      PyEmuera の .bat ファイルは動きます。
    ・最後に「Python 3.x.x」と表示されれば完了です。

■ 2-4. インストールしたのに Microsoft Store が開いてしまう場合

  (1) スタートメニューで「アプリ実行エイリアスの管理」と入力し、開きます
      （「エイリアス」と入力しても見つかります）。
  (2) 一覧の「Python (default)」に関する項目がオンになっているか確認します。
  (3) すでにオンの場合は、一度オフにしてからオンに戻すと直ることがあります。

  （参考：Python 公式ドキュメント「Using Python on Windows」
    https://docs.python.org/3/using/windows.html ）


--------------------------------------------------------------
3. PyEmuera を展開する
--------------------------------------------------------------

  ZIP ファイルは、そのままダブルクリックすると「中を見る」だけの状態になり、
  PyEmuera は動きません。必ず「すべて展開」で、普通のフォルダーに取り出してください。

  (1) 実行用 ZIP ファイルを右クリックし、「すべて展開」を選びます。
  (2) 展開先は、ドキュメントなど好きな場所で構いません。
      例：C:\Users\（あなたの名前）\Documents\PyEmuera
      フォルダー名に日本語や空白が入っていても動きます。
  (3) 「展開」を押すと、新しいフォルダーが開きます。
      PyEmuera.pyz が入っているフォルダーを開き、
      次のファイルがあることを確認してください。

        PyEmuera.pyz          … PyEmuera 本体
        Start_PyEmuera.bat    … バリアントを起動するためのファイル
        Check_PyEmuera.bat    … 遊べるかを事前に確認するためのファイル
        Diagnose_PyEmuera.bat … 不具合報告用の記録を取りながら起動するファイル
        sample                … 動作確認用のサンプルバリアント
  ソースコードは別のソース用 ZIP です。遊ぶだけなら実行用 ZIP を使います。
  LICENSE.txt、THIRD_PARTY_NOTICES.txt、licenses フォルダーは残してください。

  ※ 拡張子（.bat や .pyz）が表示されない設定のパソコンでは、
     「Start_PyEmuera」のように表示されます。種類が「Windows バッチ ファイル」の
     ものが .bat ファイルです。


--------------------------------------------------------------
4. まずサンプルで動作を確認する
--------------------------------------------------------------

  (1) 展開した PyEmuera.pyz の入っているフォルダーを開きます。
  (2) 「sample」フォルダーをマウスでつかみ、「Start_PyEmuera.bat」の上に
      重ねてから離します（ドラッグ＆ドロップ）。
  (3) 黒い画面が開き、次のような表示が出れば成功です。

        PyEmuera / ぱみゅーら 散歩帳
        非成人向けの独立した動作確認デモです。
        [0] はじめる  [1] JSONセーブを読む  [9] 終了

  (4) 「0」と入力して Enter を押すと、サンプルバリアントが始まります。
      お店の画面で「999」と入力して Enter を押すと終了し、画面が閉じます。
      （遊び方は sample フォルダーの README_ja.txt にあります）

  ※ インターネットから入手したファイルのため、起動時に「セキュリティの警告」や
     「Windows によって PC が保護されました」という画面が出ることがあります。
     入手元を確認したうえで「実行」を選んでください（後者の画面では、
     「詳細情報」を押すと「実行」ボタンが表示されます）。
  ※ 「Python 3.10 or later was not found.」と表示された場合は、2章に戻ってください。


--------------------------------------------------------------
5. バリアントを遊ぶ
--------------------------------------------------------------

■ 始める前に：バリアントのバックアップ

  PyEmuera はバリアントのファイルや Emuera のセーブデータを書き換えませんが、
  念のため、バリアントフォルダーを丸ごとコピーしてから試すことをおすすめします。

■ 「バリアントフォルダー」とは

  「ERB」フォルダーと「CSV」フォルダーが直接入っているフォルダーです。
  多くの場合、Emuera.exe と同じ場所にあります。

        バリアントフォルダー        ← これを指定します
          ├ ERB
          ├ CSV
          └ Emuera.exe など

  ダウンロードしたバリアントの ZIP を展開すると、同じ名前のフォルダーが二重に
  なっていることがあります。ERB と CSV が「直接」見える階層を選んでください。

■ 方法A：ドラッグ＆ドロップで起動する（おすすめ）

  バリアントフォルダーを「Start_PyEmuera.bat」の上にドラッグ＆ドロップします。
  サンプルのときと同じ操作です。

■ 方法B：バリアントフォルダーに置いてダブルクリックで起動する

  (1) 「PyEmuera.pyz」と「Start_PyEmuera.bat」の2つを、
      バリアントフォルダー（ERB と CSV がある場所）にコピーします。
  (2) コピーした「Start_PyEmuera.bat」をダブルクリックします。

  毎回同じバリアントを遊ぶ場合は、方法B が便利です。
  PyEmuera を新しい版に入れ替えるときは、バリアントフォルダーにコピーした
  2つのファイルも、新しい版のものに置き換えてください。


--------------------------------------------------------------
6. ゲーム中の操作
--------------------------------------------------------------

  操作の方法はバリアントによって異なります。バリアントの説明書や画面の案内も見てください。
  多くのバリアントでは、次のように操作します。

  ・画面に表示された番号（[0] や [100] など）を入力して、Enter キーを押します。
  ・名前などの文字を求められたら、文字を入力して Enter キーを押します。
  ・画面が止まって入力を待っているときは、Enter キーで先に進みます。
  ・セーブ・ロードは、バリアントのメニューから行います（7章）。
  ・ゲームをやめるときは、ゲーム内の終了メニューを使うのが安全です。

  強制的に止める場合
  ・Ctrl キーを押しながら C キーを押すと止まります。
    「バッチ ジョブを終了しますか (Y/N)?」と表示されたら Y を入力して Enter を押します。
  ・ウィンドウ右上の × ボタンで閉じても止まります。
  ・どちらの場合も、セーブしていない進み具合は失われます。

  表示について
  ・文字だけで表示します。画像は表示されません。
  ・区切り線などが折り返して崩れるときは、ウィンドウの幅を広げてください。
    それでも崩れる場合は、9章の「表示が崩れる」を見てください。

7. セーブデータと、PyEmuera が作るファイル
--------------------------------------------------------------

■ PyEmuera でセーブした場合

  バリアントフォルダーの中に「.pyemuera」というフォルダーが作られ、
  その中の「saves」フォルダーにセーブデータが保存されます。

        バリアントフォルダー\.pyemuera\saves\

  このセーブデータは PyEmuera 専用の形式です。
  バックアップするときは「.pyemuera」フォルダーごとコピーしてください。
  PyEmuera を新しい版に入れ替える前にも、「.pyemuera」をコピーしておくと安心です。

■ Emuera で遊んでいたセーブデータ

  バリアントフォルダー（または sav フォルダー）にある Emuera のセーブデータ
  （save00.sav など）は、自動で読み込まれます。PyEmuera はこれらのファイルを
  書き換えたり、削除したりしません。

  同じ番号のセーブがある場合は、次の順に探して、最初に見つかったものを読み込みます。
    (1) .pyemuera\saves にある PyEmuera のセーブ
    (2) .pyemuera\native-saves にある Emuera 形式のセーブ（11章の --save-format）
    (3) Emuera のセーブ（save00.sav など）
  つまり、PyEmuera で一度セーブした番号は、それ以降 PyEmuera のセーブが使われます。
  ゲームの中でセーブを削除した場合は、PyEmuera のセーブを消し、元の Emuera の
  セーブは消さずに「.pyemuera\deleted-saves」に「削除済み」の印を残します。

  ※ PyEmuera でセーブした続きは、そのままでは Emuera 側には反映されません。
  ※ Emuera 形式で書き出す機能（11章の --save-format）もありますが、
     すべての変数・バリアントでの互換性は確認されていません。

■ PyEmuera が作るファイルの一覧

  バリアントフォルダー\.pyemuera\
      saves          … セーブデータ（標準）
      native-saves   … Emuera 形式のセーブ（--save-format を指定したとき）
      deleted-saves  … ゲーム内で削除したセーブの印
      logs           … バリアントがログ出力機能を使ったときのログ
      その他         … バリアントが保存したキャラクターデータやテキスト
  PyEmuera のフォルダー\reports\
      … Check_PyEmuera.bat と Diagnose_PyEmuera.bat の記録
  11章のオプションで記録ファイルの出力先を指定した場合は、指定した場所
  --analysis を使った場合は、バリアントフォルダーの Analysis.log（または指定した場所）

8. 遊べるかどうかを事前に確認する
--------------------------------------------------------------

  バリアントフォルダーを「Check_PyEmuera.bat」の上にドラッグ＆ドロップします。
  バリアントは始まらず、ERB と CSV を読み込んで問題がないかだけを確認します。
  確認が終わると結果が表示され、「続行するには何かキーを押してください」で止まります。
  結果を読んだら、何かキーを押して画面を閉じてください。

  ・「Result: no known issue was found ...」
      → 読み込みの段階では問題が見つかりませんでした。
        ただし、バリアントの最後まで動くことの保証ではありません。
  ・「Result: issues were found ...」
      → 上の行に、問題のあるファイル名と行番号が表示されます。
        「解釈できない行です」と出る場合は、PyEmuera が対応していない命令
        （画像・音声・拡張版の命令など）が使われている可能性があります。
  ・「PyEmuera stopped ...」
      → 確認そのものができませんでした。直前のメッセージを見て、9章を参照してください。

  確認結果は、PyEmuera のフォルダー内の「reports」フォルダーにも
  check-（数字）.json という名前で保存されます。

9. 困ったとき
--------------------------------------------------------------

■ 「Python 3.10 or later was not found.」と表示される

  Python が入っていないか、古いか、見つからない状態です。2章を見てください。
  Python を入れた直後の場合は、一度コマンド プロンプトで「python --version」を
  実行し、バージョンが表示されることを確認してから、もう一度試してください。

■ 「PyEmuera.pyz was not found next to this file.」と表示される

  .bat ファイルと PyEmuera.pyz が別の場所にあります。同じフォルダーに置いてください。
  ZIP を「すべて展開」せずに、ZIP の中から実行した場合もこの表示になります（3章）。

■ 「E_NO_ERB: Game directory not found.」と表示される

  渡したフォルダーの中に ERB フォルダーが見つかりません。
  ・ERB と CSV が直接入っているフォルダーをドロップしてください（5章）。
    その1つ上や1つ下のフォルダーを渡していることがよくあります。
  ・Start_PyEmuera.bat を何もドロップせずにダブルクリックした場合も、
    .bat のあるフォルダーにバリアントがないため、この表示になります。

■ 黒い画面がすぐに閉じてしまう

  ・バリアントが正常に終了したときは、画面は自動で閉じます（エラーではありません）。
  ・エラーで止まった場合は「PyEmuera stopped (exit code …)」と表示され、
    キーを押すまで画面は閉じません。
  ・それでも一瞬で閉じて何も読めない場合は、11章の方法でコマンド プロンプトから
    起動すると、画面が閉じずにメッセージを確認できます。

■ 文字化けする

  多くのバリアントは自動で正しく読み込めます。
  それでも化ける場合は、バリアントのファイルが特殊な文字コードで保存されている
  可能性があります（11章の --encoding）。

■ 表示が崩れる（区切り線がずれる、折り返す）

  ・ウィンドウの幅を広げてください。
  ・罫線や記号の幅がずれる場合は、11章の方法で
    「--ambiguous-width 2」を付けて起動すると直ることがあります。
  ・1行の幅を変えたいときは「--columns 120」のように指定できます（標準は 100）。

■ 「解釈できない行です」「E_SYNTAX」と表示されてバリアントが始まらない

  PyEmuera が対応していない書き方や命令が含まれています。
  画像・音声・マウスを使う命令や、EE / EM 版専用の命令は対応していません。
  現時点ではそのバリアントを PyEmuera で遊ぶことはできません。

■ 起動はしたが、バリアントの途中でエラーが表示されて止まった

  画面の最後に表示されたメッセージを確認してください。
  「E_」で始まる英字がエラーの種類です。例：
    E_PLATFORM … この環境では使えない機能（キー状態の取得など）が使われました
    E_FUNCTION … 対応していない関数が使われました
    E_INPUT_EOF … 入力が途切れました（通常のプレイでは起きません）
  同じ場面で何度も止まる場合は、10章の方法で記録を取り、報告をお願いします。

■ 入力しても反応しない・止まったように見える

  ・入力待ちの状態かもしれません。番号を入力して Enter を押してみてください。
  ・大きなバリアントでは、読み込みや一部の場面に時間がかかることがあります。
    Emuera より処理が遅い場合があります。しばらく待ってみてください。
  ・それでも動かない場合は、Ctrl+C で止めて（6章）、10章の方法で報告してください。

■ 日本語入力（名前の入力など）がうまくいかない

  Windows環境で、IMEを使った日本語入力とWindows Terminal（ConPTY）上の
  入力・中断が正常に動作することを確認しています。すべてのIME製品・
  バージョン・設定の組み合わせを網羅したものではありません。
  問題が起きた場合は、利用した環境と操作を10章の方法で報告してください。


--------------------------------------------------------------
10. 不具合を報告するとき
--------------------------------------------------------------

■ 記録を取る

  (1) バリアントフォルダーを「Diagnose_PyEmuera.bat」の上にドラッグ＆ドロップします。
  (2) いつも通り遊び、問題が起きる場面まで進めます。
  (3) 終了すると、今回生成された読み取り可能なJSON記録の保存先が表示されます。
      「reports\run-…」という実行ごとの専用フォルダーに、
      check.json、session.json、error.json を保存します
      （error は、エラーで止まった場合に作られます）。
      一部のみ生成、未生成、読み取り不能な記録は、その状態が表示されます。
      以前の実行の記録が、今回生成された記録として案内されることはありません。

■ 報告に書くこと

  ・PyEmuera のバージョン
      （Diagnose の記録の中の "engine_version"、または 11章の --version で表示されるもの。
        このガイドの版は 3.0.0b2 です）
  ・Windows のバージョン（Windows 10 / 11 など）
  ・Python のバージョン（2-2 の「python --version」で表示されたもの）
  ・バリアントの名前とバージョン
  ・どの場面で、何をしたら、何が起きたか（再現する手順）
  ・画面に表示されたエラーメッセージ
  ・上で作った記録ファイル

■ 共有する前に必ず確認してください

  記録ファイルや画面の写しには、次のものが含まれることがあります。
    ・バリアントのファイル名・関数名・エラーメッセージ（バリアントの文章を含むことがあります）
    ・画面に表示されたバリアントの文章や、入力した文字（名前など）
    ・フォルダーの場所（パソコンのユーザー名を含むことがあります。
      画面の写しや、エラーメッセージに含まれる場合があります）
  内容を確認し、共有したくない部分がある場合は、その記録を送らないか、
  文章で状況を説明してください。
  バリアント本体のファイルやセーブデータを、許可なく他の人に渡さないでください。

11. 上級者向け：コマンドで起動する
--------------------------------------------------------------

  オプションを付けて起動したいときは、コマンド プロンプトを使います。

  (1) PyEmuera のフォルダーをエクスプローラーで開きます。
  (2) 上部のアドレス欄をクリックし、「cmd」と入力して Enter を押します。
      そのフォルダーでコマンド プロンプトが開きます。
  (3) 次のように入力して Enter を押します。

        Start_PyEmuera.bat "D:\Games\バリアントフォルダー" --columns 120

      バリアントフォルダーの場所は、フォルダーをコマンド プロンプトに
      ドラッグ＆ドロップすると自動で入力されます。

  よく使うオプション
    --version                PyEmuera のバージョンを表示する
    --help                   すべてのオプションを表示する（英語）
    --columns 数字           1行の幅（標準 100）
    --ambiguous-width 2      罫線などの記号を2文字分の幅として扱う
    --color never            文字の色付けをしない
    --encoding cp932         バリアントのファイルの文字コードを指定する
                             （通常は自動判定のため不要）
    --save-format 形式        セーブの形式（json＝標準 / emuera-text / emuera-binary）
                             emuera-text / emuera-binary は
                             「.pyemuera\native-saves」に書き出します
    --check                  バリアントを始めずに事前確認だけを行う（8章と同じ）

  例：バージョンを表示する
        Start_PyEmuera.bat --version

  Python を直接使う場合は、次のようにも起動できます。

        python PyEmuera.pyz "D:\Games\バリアントフォルダー"

  Linux の場合
    Python 3.10 以上が入っていれば、端末で次のように起動します。

        python3 PyEmuera.pyz "/path/to/バリアントフォルダー"

    .bat ファイルは Windows 専用です。Check と Diagnose に相当する操作は、
    それぞれ「--check --report 記録.json」「--session-report 記録.json
    --error-report 記録.json」を付けて起動します。
    macOS での動作は確認していません。

12. 安全に使うための注意
--------------------------------------------------------------

  ・PyEmuera はインターネットに接続しません
    （2章の Python のインストールでは、Python 側がインターネットを使います）。
  ・バリアントの ERB / CSV / 設定ファイル、Emuera のセーブデータは書き換えません。
  ・PyEmuera が書き込む場所は、7章の「PyEmuera が作るファイルの一覧」のとおりです。
    バリアントフォルダーの中の「.pyemuera」、PyEmuera のフォルダーの「reports」、
    オプションで指定した場所に書き込みます。
  ・成人向けの内容を含むバリアントがあります。年齢制限など、バリアントの利用条件に従ってください。
  ・PyEmuera は Emuera の公式版ではありません。PyEmuera についての質問を、
    Emuera やバリアントの作者に問い合わせないでください。

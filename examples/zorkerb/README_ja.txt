ZORKERB r29 — Zork I の非公式 ERB 移植

ZORKERB は Zork I・II・III の ERB 移植を目指す独立プロジェクトです。
この同梱版は Zork I Release 119 / Serial 880429 に対応します。入力は英語です。

起動: python PyEmuera.pyz ZORKERB
Windows では ZORKERB フォルダーを Start_PyEmuera.bat にドラッグ＆ドロップできます。
Z-machine や Frotz は必要ありません。

ZORKERB: https://github.com/Meistertech-JP/ZORKERB
Release r29: https://github.com/Meistertech-JP/ZORKERB/releases/tag/r29
